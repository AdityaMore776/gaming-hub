# WorldWander (Simple International Travel Website)

A simple international travel booking website made with plain HTML, CSS and JavaScript.
This is a **separate project** from both the Gaming Hub website and the national travel
website. It does not use PHP, a database, or any files from those projects.

## Pages

| File            | What it is                                                   |
|-----------------|--------------------------------------------------------------|
| `index.html`    | Home page with a "Surprise Me!" random destination button    |
| `europe.html`   | Europe tours (click "More Info" to show trip details)        |
| `asia.html`     | Asia tours (click "More Info" to show trip details)          |
| `register.html` | Sign-up form with live total price and a booking ticket      |
| `style.css`     | All the styling                                              |
| `script.js`     | All the JavaScript for the pages                             |

## How to run

No installation needed. Open `index.html` in any web browser
(Chrome, Edge, Firefox) by double-clicking it.

Note: the sign-up form does not save data anywhere. It only shows a booking ticket on screen.
