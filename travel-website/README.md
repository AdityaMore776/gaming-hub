# India Travels (Simple Travel Booking Website)

A very simple national travel booking website made with plain HTML, CSS and JavaScript.
This is a **separate project** from the Gaming Hub website in this repository. It does not
use PHP, a database, or any of the Gaming Hub files.

## Pages

| File             | What it is                         |
|------------------|------------------------------------|
| `index.html`     | Home page                          |
| `beaches.html`   | Listing page: beach trips          |
| `mountains.html` | Listing page: mountain trips       |
| `register.html`  | Registration form                  |
| `style.css`      | All the styling                    |
| `script.js`      | Checks the form and shows a message|

## How to run

No installation needed. Open `index.html` in any web browser
(Chrome, Edge, Firefox) by double-clicking it.

Note: the registration form does not save data anywhere. It only checks that all
fields are filled in and shows a thank-you message.
